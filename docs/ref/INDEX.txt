Tooling note: C:\Users\tyler\tools\dump.sh + ghidra-scripts\Dump.java replaces decomp.sh for new
work - one headless run mixes d:<addr> decompile, a:<addr> disassemble a function, x:<addr> raw
disassembly from an address, r:<addr> references to a data address. Use a:/x: whenever a callee
takes arguments in registers (FUN_007ed3b0 does), since the decompiler silently drops them.

binding-table entries (ref-tables.jsonl "table" field) are the ENTRY address, not the table base,
so a class's methods occupy a consecutive run. That makes the run an independent check on which
class a duplicated method name belongs to, and it disagrees with the name matcher: HasScript has
three byte-identical bodies, and the matcher offered 004a7480 for CSimpleFrame when the frame's is
0049eab0 (entry 00ac15b8, inside the frame's run 00ac15b8-00ac1730; object type DAT_00b49984).
